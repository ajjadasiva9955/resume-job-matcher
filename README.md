# 🚀 AI-Powered Resume Job Matcher & Career Agent : 
## 🌐 Live Demo
https://resume-job-matcher-i3m4.onrender.com

An AI-powered web application that analyzes resumes, matches them with job descriptions, identifies skill gaps, generates personalized learning roadmaps, creates professional cover letters, and recommends relevant jobs.

## ✨ Features
- Resume Upload & Analysis
- AI Skill Gap Detection
- Personalized Learning Roadmap
- AI Cover Letter Generator
- Job Recommendations
- Responsive Web Interface

## 🛠 Tech Stack
- Python
- Flask
- Google Gemini AI
- SerpAPI
- HTML, CSS, JavaScript
- Git & GitHub
- Render

## ⚙ Installation

```bash
git clone https://github.com/ajjadasiva9955/resume-job-matcher.git
cd resume-job-matcher
pip install -r requirements.txt
python app.py
```
